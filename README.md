# Create: Enchantment Industry Fly

Create: Enchantment Industry Fly brings the core experience and enchantment automation from Create: Enchantment Industry to the Fabric-based Create Fly ecosystem.

The current `2.5.2` build is a **beta** for Minecraft 26.1.2. Back up worlds before updating or testing it.

## Requirements

- Minecraft 26.1.2
- Java 25
- Fabric Loader 0.19.3 or newer
- Fabric API 0.155.2+26.1.2 or newer for Minecraft 26.1.2
- Create Fly 26.1.2-6.0.9-4
- Create: Dragons Plus Fly 1.11.4-p1
- JEI 29.6.2.38 is optional

## Included content

- Mechanical Grindstone and Grindstone Drain
- Experience Hatch, Printer, Experience Lantern and experience fluids
- Blaze Enchanter, Blaze Forger and Classic Blaze Enchanter
- Core recipes, advancements, Ponder scenes and JEI integration

## Notes for players and modpack authors

- This release does not promise in-place upgrades from 1.21.11 worlds. Create a new 26.1.2 world for evaluation and keep a backup before attempting any migration.
- NeoForge 1.21.1 worlds, block entity data and TOML configuration files are not migrated.
- Configuration files are JSON files under `config/create_enchantment_industry/`.
- Apothic Enchanting and Apotheosis are NeoForge-only on 26.1.2, while Sable has no compatible 26.1.2 Fabric release. Their integrations are therefore not part of this Fabric/Create Fly build.
- Report reproducible issues with the full game log and a minimal mod list where possible.
