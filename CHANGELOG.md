# Create: Enchantment Industry Fly 2.5.1-p.1

This is **Preview 1** of Create: Enchantment Industry Fly for Minecraft 1.21.11. The release channel is **ALPHA**.

## Highlights

- Ported the core Create: Enchantment Industry experience to Fabric and Create Fly.
- Includes the Mechanical Grindstone, experience storage and transport, printing, all three Blaze devices, Ponder scenes and optional JEI support.
- Restored Create goggle information for CEI machines and storage blocks.
- Fixed Blaze device inventory models, Ponder text and Mechanical Arm demonstrations.
- Fixed experience fluid evaporation and Experience Lantern absorption, storage display and world lighting.

## For modpack authors

- Requires Minecraft 1.21.11, Fabric Loader, Fabric API, Create Fly 1.21.11-6.0.9-5 and Create: Dragons Plus Fly 1.11.4-p2.
- Configuration now uses JSON files under `config/create_enchantment_industry/`; old NeoForge TOML files are not imported.
- The former Apothic Enchanting, Apotheosis, Sable, Sable-Apotheosis and Touhou Little Maid integrations are not included.
- This preview is intended for new worlds and does not migrate NeoForge 1.21.1 saves.

## Preview notice

Back up worlds before playing and report reproducible issues with the full game log.
